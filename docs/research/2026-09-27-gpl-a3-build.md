# GPL-A3 built: liveness masks replace the general patch loop's refcounts (2026-09-27)

Stage 1 of `docs/research/2026-09-27-general-patch-loop.md` (the design), plus the cheap
half of its stage 2. Branch `perf/gpl-a3`, base origin/master `1f9c3414` (owner's go:
decisions.jsonl `GPL-A3-BUILD`). Every figure below was measured in this parcel with
`oracle-aether` md5 `3e7c2778` (the rebuild of 2026-09-26 21:55Z); base and A3 always on the
same binary. The ROMs are FAST builds (byte-identical to canonical ones; CRCs in
`2026-09-27-gpl-a3-build/results/builds.txt`). No emulator MCP tool was used.

## What was built

- **`Page_Live_Masks`** (engine/ram.emp, RAM tail, both shapes): one u16 frame bitmask per
  tile-cache row, then one per column. Invariant, general regime: every cache cell (r, c)
  names a frame in row r's mask or column c's mask.
- **The insertion barrier** in `pc_patch_run_loop`: `bset d2, d4` per word, and the wrapping
  proc ORs `d4` into the run's mask once per run. A sequential run's mask is the row
  `TileCache_FillRow` publishes (`Page_Live_RowPtr`, general regime only); a column run's is
  derived from the physical column its caller already holds in `d1`
  (`PageCache_PatchRun_Col` now takes it as an input).
- **`PageCache_LiveSweep`** (VSync_Wait's idle slot, after the DEBUG audit): re-derives one row
  or column exactly at a time, gated like the audit; each full rotation stamps every frame it
  saw named. `PageCache_LiveSweepAll` (rows exact, columns cleared at one instant) at
  `EndBoundedRegime` and as `PageCache_PickVictim`'s one forced sweep. `PageCache_LiveReset`
  right after `TileCache_FillAll`'s bulk zero. `PageCache_LiveUnion` for choices.
- **`PageCache_PickVictim`**: the oldest assigned, unpinned, unheld frame in no mask; frames
  seen live are stamped now and drop their demand hold; none -> forced sweep -> thrash.
- **The GPL-2 demand hold carried over** (flag, gate, `PageCache_DemandHoldTick`). Its release
  test "refcount 0" became "in no mask": such a frame is stamped now; a named one only drops
  the mark.
- **The audit**: the general regime's check is per word (assigned, and in its row or column
  mask), sliced like the latched one, so the 200k-cycle atomic walk is gone (**AA-1 closed**).
  Two messages: "general regime: a cache word names an UNASSIGNED frame" / "a cache word names
  a frame its row and column liveness masks both omit". Under a latch, arm (a) is "every mask
  keeps its reset value", checked per slice (slice s: row s/2, column s mod 80).

**Deleted:** `pf_refcount` (the field is `pf_pad`, for the 8-byte stride), `PF_EVICTABLE` and
every transition of it, the refcount rebuild in `EndBoundedRegime`, the refcount audit sum,
`Page_Audit_Scratch` (30 B DEBUG), the candidate-flag audit checks, the orphan check (its
state no longer exists: an assigned, unpinned, unheld frame is a candidate the moment no mask
names it, so the one leak left is "held, gate disarmed", which is checked), and
`PageCache_ResetRefcounts` (now `PageCache_ReleaseHolds`, same DEBUG-only placement).

**Deviations from the design, all measured:**
1. u16 masks, not u32 (`PAGE_FRAMES_MAX` = 15 <= 16, ensure'd). Half the RAM.
2. The hold stays GPL-2's per-frame flag, not a new mask; the idle sweep does not release holds
   (a choice that sees the frame named does, and DemandHoldTick bounds the rest).
3. The column run is handed its column instead of reading a published pointer, and the latched
   arm (a) is sliced. Both came out of a bisect (below): the design's shapes cost the latched
   regimes a frame each.
4. The idle sweep stamps what it sees named once per rotation (the eviction-order measurement,
   below). Order only.

## The audit arms, and how each is proven

`tools/pagecache_audit_poison.py` on the tip's `s4.debug.bin` (`bf579aed`): 15 arms, exit 0
(`results/poison_final.log`). Red-first, each mutation made on disk in
`engine/level/page_cache.emp`, FAST-built, and restored from `git show HEAD:<path>` with the
tree checked clean (`results/builds.txt`):

| mutation (final code) | arm that went red | every other arm |
|---|---|---|
| a: both `bne .lm_moved` -> `nop` | (a) row mask moved, (a2) column mask moved | as designed |
| g1: the UNASSIGNED raise -> `rts` | (g1) | as designed |
| g2: the "masks both omit" raise -> `rts` | (g2) | as designed |
| col: the column-mask test -> `jbra .gw_unmasked` | (g3) row omits / every column carries: halts | as designed |

Arms: (a)/(a2) latched mask moved (message named); (b) (c) (b1) (b2) unchanged; (g0) general
regime forced with valid masks, must run; (g1) planted unassigned word, UNASSIGNED message;
(g2) planted word whose frame its row omits, "masks both omit" message; (g3) the same with every
column carrying it, must run; (h) hold with the gate disarmed halts; (hr) armed hold is
released (flag, gate, and the stamp moved). The old (o) orphan arm is retired: its planted state
(assigned, unpinned, no candidate flag) is an ordinary frame under the masks. The (g) arms first
make the masks a valid superset (all frames in every row), as `EndBoundedRegime` does at the real
flip; without that the old arm (g) would halt on every word, not the planted one. (g2)/(g3)
plant in the next slice the audit reads: the idle sweep would otherwise heal a cleared bit
before the audit reached it (the sweep runs after the audit in the idle slot).

Harness notes, stated because they cost a re-run: two first-round mutant runs lost their
emulator mid-run ("bus connection closed") under a load average of ~16, and one second-round
run read a garbage boot state (`Direct_Map=$F8`, every frame "assigned") and exited COULD NOT
RUN. All three were re-run alone and gave the clean results above; no verdict is taken from a
run that did not complete.

## Stage 2: the general regime now runs in a lane

`tools/general_regime_witness.py`: the clip DEBUG ROM's two Chemical Plant legs (right to
x 14400, then down / diagonal), a fresh private `oracle-aether` each, stepped per frame; exit 1
on any halt, naming the raise; UNMEASURABLE unless each leg turned, spent >= 300 frames in the
general regime and saw an eviction. Wired in `tools/keepalive_manifest.toml` beside the clip
layer-line witness (the nightly `tools/nightly_instrument_keepalive.sh` builds DEBUG
`S2CLIP=s2_ehz_cpz`; landing_build builds no clip shape). Red-first on the final code: the row
barrier's `or.w` dropped -> both legs halt ("masks both omit"); the column barrier's dropped ->
the diagonal halts, the straight-down leg (no column runs) passes. Base (refcounts) and tip both
PASS: 1,096 general-regime frames and 4 / 5 evictions per leg.

**Not built:** a derived lag ceiling. The design asked for one "if cheap"; a ceiling copied from
one run is a number, not a derivation, so the lane gates correctness only.

## The eviction-order change, measured

`2026-09-27-gpl-a3-build/evict_order_probe.py` flies a zigzag and reads Page_Table every frame:
evictions, loads, and **re-loads** (a load of a page evicted earlier in the run: the cost of a
choice that turned out wrong), plus the DEBUG demand-stall count. Same camera path per drive.

| drive (ticks) | build | evictions | re-loads | demands | lag |
|---|---|---|---|---|---|
| clip zigzag (~4,080) | base (release time) | 27 | 22 | 4 | 147 |
| | A3, stamps at choices only | 29 | 24 | 3 | 52 |
| | A3 tip (+ rotation stamps) | 27 | **22** | 4 | 50 |
| STRESS_ART zigzag (987) | base | 20 | 11 | 0 | 51 |
| | A3, choices only | 23 | 14 | 3 | 17 |
| | A3 tip | 21 | **12** | 3 | 15 |

The design's "last observed live" order (stamped only at eviction choices) cost +2 / +3
re-loads under churn. The tip's rotation stamps bring the clip back to the refcount design's 22
and STRESS_ART to 12 against 11. The 3 demand stalls on STRESS_ART are not attributed to the
order: A3 flies the same 987 ticks in 34-36 fewer video frames, so the decoder gets less time
per tick; the lag gain confounds that count.

## Cost

- **RAM:** `Page_Live_Masks` 280 B + row pointer 4 + sweep cursor 2 + rotation set 2 (both
  shapes); DEBUG `Page_Live_Forced` 2, `Page_Audit_Scratch` -30. Engine RAM +288 B release,
  +260 B DEBUG. Free RAM above the game (initial SP - `Game_RAM_End`): release 16,126 -> 15,870 B,
  DEBUG 3,792 -> 3,536 B (the design estimated ~3,216).
- **Idle CPU:** the sweep (~2.4k cycles a unit, ~13k/tick of idle in the band), the general
  audit slices (~2.8k each). Neither runs in the tick; both gated on the scanline and
  `VBlank_Flag`.
- **Latched regimes:** one `tst.b/bne` per FillRow call and one `jbsr/tst.b/bne/rts` per frame
  in VSync_Wait. Measured: nothing.

  `Page_Live_Masks`, `PageCache_LiveReset`; vblank -> `PageCache_LiveSweep`; ojz_scroll_test ->
  `PageCache_ReleaseHolds`. `PageCache_PatchRun_Col` gained an input (`d1`).
- Removed: `PageCache_ResetRefcounts`, `PF_EVICTABLE`, `PF_EVICTABLE_BIT`, `Page_Audit_Scratch`;
  field `pf_refcount` renamed `pf_pad`.
- Sigil: no change. Its `tile_cache_port` hand-supplies cross-seam names for a strict-gate run;
  the new RAM names and `PageCache_LiveReset` are not in its list (neither were GPL-2's). Aeon
  lands alone; flagged for the sigil lane, not tested here.

## Open

  covered only by the shared code and the DEBUG legs.
- **The owner's look** at the clip in Chemical Plant on this build; pixels are not a gate.
- **Replay fixtures**: the DEBUG RAM layout moved (the 30 B scratch left, the masks joined the
  tail). The replay net has no automated runner (`tools/test_replay_fixture.py` checks structure
  only); whether its RAM-hash checkpoints need a re-stamp was not measured.

- **Lever B** (translate once per section/page) stays deferred as the design recommends.
